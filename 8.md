### Q: Can you use non-blocking assignments (NBA) in `assign` statements?

**A:** **No.** `assign` statements use continuous assignment, whereas non-blocking assignments are strictly procedural.

#### Simulation vs. Synthesis Behavior
* **Simulation:** Will **not** run. The simulator parser flags it as a syntax error immediately during compilation and aborts execution.
* **Synthesis:** Will **not** reach synthesis. Synthesis tools share the same language grammar frontend and will reject the code with a compilation error before building any netlist.

#### Why It Is Not Allowed
1. **Continuous vs. Procedural Context:** The `assign` keyword models combinational wires that update instantaneously. Non-blocking assignments (`<=`) are procedural timing constructs meant exclusively for sequential blocks.
2. **Language Grammar Violation:** Mixing continuous wire syntax with procedural assignment operators violates Verilog/SystemVerilog standards.

#### Summary Rule
* Use **`assign`** for continuous combinational wire connections.
* Use **non-blocking assignments (`<=`)** inside clocked procedural blocks (`always @(posedge clk)`).
