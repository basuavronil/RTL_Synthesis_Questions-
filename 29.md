### FAQ: How do Moore and Mealy FSM outputs differ in synchronous and asynchronous behavior?

While both Moore and Mealy finite state machines use **synchronous state transitions** (updating states exclusively on a clock edge), their **outputs** exhibit fundamentally different timing behaviors:

#### 1. Moore Machine: Synchronous Outputs
* **Behavior:** Moore outputs depend **only on the current state**. Even though the output logic is combinational, the outputs can only change when the state register updates on the active clock edge.
* **Implication:** The outputs are **fully synchronous** and glitch-free. Any input changes occurring mid-cycle are ignored by the output until the next clock edge triggers a state transition.

#### 2. Mealy Machine: Asynchronous (Combinational) Outputs
* **Behavior:** Mealy outputs depend on **both the current state and current inputs**. Because inputs feed directly into the output combinational logic, the outputs react **instantly** (within the same clock cycle) to input changes without waiting for a clock edge.
* **Implication:** This introduces an **asynchronous combinational path** from the input pins to the output pins. Any glitches or noise on the inputs will propagate straight through to the outputs, requiring careful handling when interfacing with downstream synchronous logic.

### Quick Summary

| Feature | Moore FSM Outputs | Mealy FSM Outputs |
| :--- | :--- | :--- |
| **Timing Nature** | Synchronous (Clock-bound) | Asynchronous / Combinational (Immediate) |
| **Response to Mid-Cycle Inputs** | Delayed until next clock edge | Immediate (0-cycle response) |
| **Glitch Susceptibility** | None (Filtered by state register) | High (Input glitches pass through) |
