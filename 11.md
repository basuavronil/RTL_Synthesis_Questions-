### What Causes an Unintended Latch? (Simulation vs. Synthesis)

An unintended latch occurs when a combinational block fails to assign a value under every possible input condition, forcing the circuit to "remember" its previous state.

#### **Common Causes & Behavior:**

* **1. Incomplete `if-else` (Missing `else`):**
  * *Simulation:* Silently retains the variable's previous value from the last cycle without throwing errors.
  * *Synthesis:* Infers an unwanted transparent latch because physical hardware cannot leave outputs floating when conditions aren't met.

* **2. Incomplete `case` Statement (Missing `default`):**
  * *Simulation:* Keeps the previous state for any unlisted input patterns.
  * *Synthesis:* Creates an unintended latch to hold state for missing case items.

* **3. Partial Signal Assignment Across Branches:**
  * *Simulation:* Maintains the unassigned value seamlessly across execution cycles.
  * *Synthesis:* Builds a latch because the output lacks a driven value in all possible branching paths.

* **4. Reading a Variable Before Assigning in All Paths:**
  * *Simulation:* Carries over prior values as variables act like software storage.
  * *Synthesis:* Infers a hardware memory element (latch) due to the implied feedback loop.
