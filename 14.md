# Verilog & SystemVerilog RTL Design FAQ

## FAQ: Intentional Latches

### How can you write an intentional latch?
You can write an intentional latch by using an incomplete conditional statement without a default value or `else` branch in a combinational block, or by using the explicit `always_latch` keyword in SystemVerilog.

---

## Writing Intentional Latches

### 1. Verilog Method (Incomplete Conditional)
If you intentionally want a latch to hold its value when an enable signal is low, you omit the `else` branch or default assignment:

```verilog
always @* begin
    if (en) begin
        q = d;
    end
    // Intentional latch: 'q' retains its previous value when 'en' is 0
end
