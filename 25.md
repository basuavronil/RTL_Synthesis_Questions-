### FAQ: Can you use both `posedge` and `negedge` of the same clock in one always block?

**No.** Standard hardware flip-flops in FPGAs and ASICs are physically designed to trigger on only **one** clock edge (either rising or falling, but not both simultaneously). 

#### 1. Why Is It Not Synthesizable?
* **Hardware Limitation:** Standard master-slave edge-triggered flip-flops sample data on a single clock transition. An `always` block sensitive to both `posedge clk` and `negedge clk` describes double-edge sampling (DDR), which standard single-pumped registers cannot map to.
* **Synthesis Error:** Synthesis tools will reject this construct, throwing a fatal error stating that edge event lists cannot mix rising and falling edges for the same clock expression.

### Code Examples: Dual-Edge Mixing vs. Separated Logic

#### ❌ The Invalid Approach (Will Fail Synthesis)
Attempting to capture both rising and falling edges in a single procedural block is illegal for standard synthesis tools.

```verilog
module invalid_dual_edge (
    input      clk,
    input      data_in,
    output reg q_out
);

    // ERROR: Mixing posedge and negedge on the same clock in one block is illegal!
    always @(posedge clk or negedge clk) begin
        q_out <= data_in; 
    end

endmodule
