> **Quick Rule of Thumb:**
> * **`casez` (Controlled Wildcards):** A match occurs if the branch has a `?`/`z` (matching *any* input `0`, `1`, `x`, `z`), or if there is a strict literal match (`0` to `0`, `1` to `1`, `x` to `x`). Safe and ideal for priority encoders when using explicit `?`.
> * **`casex` (Dangerous Wildcards):** **Virtually everything is a match.** Because `x`, `z`, and `?` act as universal wildcards on *both* sides, an uninitialized `x` in your incoming data will silently trigger a match against literal branch values. **Strongly avoid in production RTL.**


## Verilog Case Statement Comparison: Comprehensive Match Matrix

### 1. Standard `case` (Strict Exact Match)
Standard `case` requires 100% identical bit matching. Note that `?` in a branch is treated literally as a `z` (high-impedance) value, not a wildcard.

| Incoming Data | Branch Value | Does it Match? | Why? |
| :--- | :--- | :--- | :--- |
| **`0`** | **`0`** | **Yes** | Exact bit match. |
| **`0`** | **`1`** | **No** | Mismatched known values. |
| **`0`** | **`x`** | **No** | Known value does not match unknown. |
| **`0`** | **`z` or `?`** | **No** | Known value does not match high-impedance. |
| **`1`** | **`0`** | **No** | Mismatched known values. |
| **`1`** | **`1`** | **Yes** | Exact bit match. |
| **`1`** | **`x`** | **No** | Known value does not match unknown. |
| **`1`** | **`z` or `?`** | **No** | Known value does not match high-impedance. |
| **`x`** | **`0` or `1`** | **No** | Unknown does not match known values. |
| **`x`** | **`x`** | **Yes** | Exact bit match (`x` matches `x`). |
| **`x`** | **`z` or `?`** | **No** | Unknown does not match high-impedance. |
| **`z`** | **`0` or `1`** | **No** | High-impedance does not match known values. |
| **`z`** | **`x`** | **No** | High-impedance does not match unknown. |
| **`z`** | **`z` or `?`** | **Yes** | Exact bit match (`z` matches `z`/literal `?`). |

### 2. `casez` (`?` and `z` as Wildcards in Branch Only)
In `casez`, `?` or `z` written in the **branch** acts as a universal wildcard matching anything. Incoming data values cannot act as wildcards.

| Incoming Data | Branch Value | Does it Match? | Why? |
| :--- | :--- | :--- | :--- |
| **`0`** | **`0`** | **Yes** | Exact bit match. |
| **`0`** | **`1`** | **No** | Mismatched known values. |
| **`0`** | **`x`** | **No** | Literal `x` in branch is strict; no match. |
| **`0`** | **`z` or `?`** | **Yes** | Branch wildcard matches incoming `0`. |
| **`1`** | **`0`** | **No** | Mismatched known values. |
| **`1`** | **`1`** | **Yes** | Exact bit match. |
| **`1`** | **`x`** | **No** | Literal `x` in branch is strict; no match. |
| **`1`** | **`z` or `?`** | **Yes** | Branch wildcard matches incoming `1`. |
| **`x`** | **`0` or `1`** | **No** | Incoming unknown is strict; no match against literal branch values. |
| **`x`** | **`x`** | **Yes** | Exact bit match. |
| **`x`** | **`z` or `?`** | **Yes** | Branch wildcard matches incoming `x`. |
| **`z`** | **`0` or `1`** | **No** | Incoming high-impedance is strict; no match against literal branch values. |
| **`z`** | **`x`** | **No** | Literal `x` in branch does not match incoming `z`. |
| **`z`** | **`z` or `?`** | **Yes** | Branch wildcard matches incoming `z`. |

---

### 3. `casex` (`?`, `x`, and `z` as Wildcards Everywhere)
In `casex`, **any `x`, `z`, or `?` on either side** acts as a universal wildcard. If *either* the incoming data or the branch contains an unknown/high-impedance/wildcard state, **it matches unconditionally**.

| Incoming Data | Branch Value | Does it Match? | Why? |
| :--- | :--- | :--- | :--- |
| **`0`** | **`0`** | **Yes** | Exact bit match (no wildcards present). |
| **`0`** | **`1`** | **No** | Mismatched known values (no wildcards present). |
| **`0`** | **`x`, `z`, or `?`** | **Yes** | **Wildcard Trigger:** Branch contains a wildcard (`x`/`z`/`?`), matching incoming `0`. |
| **`1`** | **`0`** | **No** | Mismatched known values (no wildcards present). |
| **`1`** | **`1`** | **Yes** | Exact bit match (no wildcards present). |
| **`1`** | **`x`, `z`, or `?`** | **Yes** | **Wildcard Trigger:** Branch contains a wildcard (`x`/`z`/`?`), matching incoming `1`. |
| **`x`, `z`, or `?`** | **`0`** | **Yes** | **The Hazard:** Incoming data contains a wildcard (`x`/`z`/`?`), matching literal branch `0`. |
| **`x`, `z`, or `?`** | **`1`** | **Yes** | **The Hazard:** Incoming data contains a wildcard (`x`/`z`/`?`), matching literal branch `1`. |
| **`x`, `z`, or `?`** | **`x`, `z`, or `?`** | **Yes** | Both sides contain wildcards/unknowns, resulting in a match. |
