# Verilog/SystemVerilog Guide: Blocking (`=`) vs. Non-Blocking (`<=`) Assignments

A breakdown of event scheduling, simulation races, and synthesis mismatches in sequential logic design.

---

## The Golden Rule

* **Sequential Logic (`always @(posedge clk)`):** Use **non-blocking (`<=`)** assignments.
* **Combinational Logic (`always @(*)`):** Use **blocking (`=`)** assignments.

---

## 1. Event Scheduling & Execution Regions

Verilog event-driven simulators divide time steps into distinct execution regions:

* **Active Region:** Evaluates RHS expressions and updates **blocking (`=`)** assignments immediately.
* **NBA (Non-Blocking Assignment) Region:** Updates LHS targets for **non-blocking (`<=`)** assignments after all Active region evaluations are complete.

---

## 2. The Cross-Coupled Flop Race Condition

Consider two cross-coupled flops intended to swap values on every clock tick:

### ❌ Incorrect: Blocking Assignments (`=`)

```verilog
// Block 1
always @(posedge clk) begin
    a = b;
end

// Block 2
always @(posedge clk) begin
    b = a;
end
